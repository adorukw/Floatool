## 0. 先看清现有场景结构

你的 `panels/settings_panel.tscn` 现在是这样（根节点是 `MarginContainer`）：

```
Settings (MarginContainer, margin 12)
└── Scroll (ScrollContainer)
    └── Content (VBoxContainer, separation 16)
        ├── NoteSection
        │   ├── Header (Label) "便签"
        │   └── GridContainer (columns=2)
        │       ├── Label1 "保存路径"
        │       ├── PathRow (HBox)
        │       │   ├── PathField (LineEdit)
        │       │   └── BrowseButton (Button "浏览...")
        │       ├── Label2 "默认文件夹路径"
        │       └── OpenFolderButton (Button "打开所在文件夹")
        │   └── HSeparator
        ├── TranslateSection
        │   ├── Header (Label) "翻译"
        │   ├── Grid (columns=2)
        │   │   ├── Label1 / UrlField (LineEdit)
        │   │   ├── Label2 / KeyRow (KeyField + ShowKeyButton)
        │   │   ├── Label3 / SourceLang (LineEdit)
        │   │   └── Label4 / TargetLang (LineEdit)
        │   └── TestRow (TestButton + TestResult)
        ├── AISection
        │   ├── Header (Label) "AI 助手"
        │   ├── Grid (columns=2)
        │   │   ├── Label1 / UrlField (LineEdit)
        │   │   ├── Label2 / ModelField (LineEdit)
        │   │   ├── Label3 / KeyField (LineEdit)
        │   │   ├── Label4 / SystemPrompt (TextEdit)
        │   │   └── Label5 / SpinBox
        │   └── TestRow (TestButton + TestResult)
        ├── BottomBar (HBox)
        │   ├── Spacer
        │   ├── StatusLabel "未保存"
        │   └── SaveButton "保存设置"
        └── HotKeySection
            └── Label (一整段命令文本)
```

### 根节点类型

根节点 `Settings` 是 **`MarginContainer`**，所以脚本第一行必须是：

```gdscript
extends MarginContainer
```

不要写 `extends VBoxContainer`，否则会报：

> Script inherits from native type 'MarginContainer', so it can't be assigned to an object of type: 'VBoxContainer'

## 1. 场景里还需要补的东西

### 1.1 加两个 `HTTPRequest`

设置页要提供「测试连接」功能，需要两个 `HTTPRequest`：

| 节点名 | 用途 | `timeout` |
|--------|------|-----------|
| `DeepLTestHttp` | 测试翻译 Key | `20` |
| `AITestHttp` | 测试 AI Key / URL / Model | `60` |

操作：

1. 选中根节点 `Settings`。
2. 右键 → **Add Child Node** → `HTTPRequest` → 创建。
3. 分别改名 `DeepLTestHttp`、`AITestHttp`。
4. Inspector 里设 `timeout`。

> 两个节点都是 `Node`，不参与 UI 布局，放在根节点下即可。

### 1.2 修一下顺序和布局

| 问题 | 建议 |
|------|------|
| `HotKeySection` 在 `BottomBar` **后面** | 把它移到 `BottomBar` **前面**，让「保存设置」按钮在最底部 |
| `HotKeySection` 没有标题 | 加一个 `Label`，文字「快捷键」，字号 20 |
| `HotKeySection` 只有一段文本 | 加一个 `CopyButton`（Button，文字「复制命令」），方便复制到桌面环境 |
| `Content` 没有横向 Expand | 选中 `Content` → **Size Flags Horizontal = Expand Fill**，否则设置项可能不铺满宽度 |
| `AI KeyField` 没设密码模式 | 设 `secret = true`，并加一个 `ShowKeyButton`（可选） |
| `SystemPrompt` 太矮 | 设 `custom_minimum_size = Vector2(0, 80)` |
| `SpinBox` 没范围 | 在 Inspector 里设 `min_value = 1`、`max_value = 100`、`step = 1`、`value = 20` |
| `HotKeySection` 的命令少了 `settings` | 补一条 `printf %s settings ...` |

### 1.3 给根节点挂脚本

选中 `Settings` → **Attach Script** → 路径 `res://panels/settings_panel.gd`。

## 2. 完整脚本

把下面内容保存到 `panels/settings_panel.gd`：

```gdscript
extends MarginContainer

# ---------- 便签 ----------
@onready var note_path: LineEdit = $Scroll/Content/NoteSection/GridContainer/PathRow/PathField
@onready var browse_button: Button = $Scroll/Content/NoteSection/GridContainer/PathRow/BrowseButton
@onready var open_folder_button: Button = $Scroll/Content/NoteSection/GridContainer/OpenFolderButton

# ---------- 翻译 ----------
@onready var deepl_url: LineEdit = $Scroll/Content/TranslateSection/Grid/UrlField
@onready var deepl_key: LineEdit = $Scroll/Content/TranslateSection/Grid/KeyRow/KeyField
@onready var show_deepl_key_button: Button = $Scroll/Content/TranslateSection/Grid/KeyRow/ShowKeyButton
@onready var source_lang: LineEdit = $Scroll/Content/TranslateSection/Grid/SourceLang
@onready var target_lang: LineEdit = $Scroll/Content/TranslateSection/Grid/TargetLang
@onready var deepl_test_button: Button = $Scroll/Content/TranslateSection/TestRow/TestButton
@onready var deepl_test_result: Label = $Scroll/Content/TranslateSection/TestRow/TestResult

# ---------- AI ----------
@onready var ai_url: LineEdit = $Scroll/Content/AISection/Grid/UrlField
@onready var ai_model: LineEdit = $Scroll/Content/AISection/Grid/ModelField
@onready var ai_key: LineEdit = $Scroll/Content/AISection/Grid/KeyField
@onready var ai_prompt: TextEdit = $Scroll/Content/AISection/Grid/SystemPrompt
@onready var ai_history: SpinBox = $Scroll/Content/AISection/Grid/SpinBox
@onready var ai_test_button: Button = $Scroll/Content/AISection/TestRow/TestButton
@onready var ai_test_result: Label = $Scroll/Content/AISection/TestRow/TestResult

# ---------- 底部 ----------
@onready var status_label: Label = $Scroll/Content/BottomBar/StatusLabel
@onready var save_button: Button = $Scroll/Content/BottomBar/SaveButton

# ---------- 其他 ----------
@onready var scroll: ScrollContainer = $Scroll
@onready var hotkey_label: Label = $Scroll/Content/HotKeySection/Label

# 可选：如果你按 1.2 加了「复制命令」按钮
@onready var copy_hotkey_button: Button = get_node_or_null(
	"Scroll/Content/HotKeySection/CopyButton"
)

# 测试用 HTTPRequest（按 1.1 添加）
@onready var deepl_http: HTTPRequest = get_node_or_null("DeepLTestHttp")
@onready var ai_http: HTTPRequest = get_node_or_null("AITestHttp")


func _ready() -> void:
	# 按钮事件
	browse_button.pressed.connect(_on_browse_pressed)
	open_folder_button.pressed.connect(_on_open_folder_pressed)
	show_deepl_key_button.pressed.connect(_on_show_deepl_key_pressed)
	save_button.pressed.connect(_on_save_pressed)
	deepl_test_button.pressed.connect(_on_deepl_test_pressed)
	ai_test_button.pressed.connect(_on_ai_test_pressed)

	if copy_hotkey_button:
		copy_hotkey_button.pressed.connect(_on_copy_hotkey_pressed)

	# HTTP 回调
	if deepl_http:
		deepl_http.request_completed.connect(_on_deepl_test_completed)
	if ai_http:
		ai_http.request_completed.connect(_on_ai_test_completed)

	# SpinBox 范围
	ai_history.min_value = 1
	ai_history.max_value = 100
	ai_history.step = 1

	_load_from_settings()


# 切到设置页 / 窗口重新获得焦点时调用
# 只回到顶部，不重新读取配置，避免冲掉用户还没保存的修改
func activate() -> void:
	scroll.scroll_vertical = 0


# ---------------- 读取配置 ----------------

func _load_from_settings() -> void:
	note_path.text = Settings.note_path()

	deepl_url.text = Settings.deepl_url()
	# 这里读「配置文件里的原始值」，而不是 deepl_key()；
	# 因为 deepl_key() 可能优先返回环境变量，写回时会把环境变量存进配置文件。
	deepl_key.text = str(Settings.get_value("translate", "deepl_key", ""))
	source_lang.text = str(Settings.get_value("translate", "source_lang", "EN"))
	target_lang.text = str(Settings.get_value("translate", "target_lang", "ZH"))

	ai_url.text = Settings.ai_base_url()
	ai_model.text = Settings.ai_model()
	ai_key.text = str(Settings.get_value("ai", "api_key", ""))
	ai_prompt.text = str(Settings.get_value("ai", "system_prompt", ""))
	ai_history.value = int(Settings.get_value("ai", "max_history", 20))

	status_label.text = "已加载"


# ---------------- 保存配置 ----------------

func _save_to_settings() -> void:
	Settings.set_value("note", "save_path", note_path.text.strip_edges())

	Settings.set_value("translate", "deepl_url", deepl_url.text.strip_edges())
	Settings.set_value("translate", "deepl_key", deepl_key.text.strip_edges())
	Settings.set_value("translate", "source_lang", source_lang.text.strip_edges().to_upper())
	Settings.set_value("translate", "target_lang", target_lang.text.strip_edges().to_upper())

	Settings.set_value("ai", "base_url", ai_url.text.strip_edges())
	Settings.set_value("ai", "model", ai_model.text.strip_edges())
	Settings.set_value("ai", "api_key", ai_key.text.strip_edges())
	Settings.set_value("ai", "system_prompt", ai_prompt.text)
	Settings.set_value("ai", "max_history", int(ai_history.value))

	Settings.save()
	status_label.text = "已保存"


func _on_save_pressed() -> void:
	_save_to_settings()


# ---------------- 便签路径 ----------------

func _on_browse_pressed() -> void:
	var dlg := FileDialog.new()
	dlg.file_mode = FileDialog.FILE_MODE_SAVE_FILE
	dlg.access = FileDialog.ACCESS_FILESYSTEM
	dlg.use_native_dialog = true
	dlg.add_filter("*.md", "Markdown")

	var current := note_path.text.strip_edges()
	if not current.is_empty():
		dlg.current_path = ProjectSettings.globalize_path(current)

	dlg.file_selected.connect(func(path: String) -> void:
		note_path.text = path
		dlg.queue_free()
	)
	dlg.canceled.connect(dlg.queue_free)

	add_child(dlg)
	dlg.popup_centered_ratio(0.6)


func _on_open_folder_pressed() -> void:
	var path := note_path.text.strip_edges()
	if path.is_empty():
		path = "user://note.md"

	var absolute := ProjectSettings.globalize_path(path)
	var dir := absolute.get_base_dir()

	if DirAccess.dir_exists_absolute(dir):
		OS.shell_open(dir)
	else:
		status_label.text = "文件夹不存在：" + dir


# ---------------- 密钥显示/隐藏 ----------------

func _on_show_deepl_key_pressed() -> void:
	deepl_key.secret = not deepl_key.secret
	show_deepl_key_button.text = "🙈" if deepl_key.secret else "👁"


# ---------------- 复制快捷键命令 ----------------

func _on_copy_hotkey_pressed() -> void:
	DisplayServer.clipboard_set(hotkey_label.text)
	status_label.text = "命令已复制"


# ---------------- 测试 DeepL ----------------

func _on_deepl_test_pressed() -> void:
	if deepl_http == null:
		deepl_test_result.text = "缺少 DeepLTestHttp 节点"
		return

	var url := deepl_url.text.strip_edges()
	var key := deepl_key.text.strip_edges()

	if url.is_empty() or key.is_empty():
		deepl_test_result.text = "请先填写接口地址和 Key"
		return
	if deepl_http.get_http_client_status() != HTTPClient.STATUS_DISCONNECTED:
		return

	deepl_test_button.disabled = true
	deepl_test_result.text = "测试中…"

	var body := "text=hello&target_lang=ZH"
	var headers := [
		"Authorization: DeepL-Auth-Key " + key,
		"Content-Type: application/x-www-form-urlencoded",
	]

	var err := deepl_http.request(url, headers, HTTPClient.METHOD_POST, body)
	if err != OK:
		deepl_test_button.disabled = false
		deepl_test_result.text = "请求失败：" + error_string(err)


func _on_deepl_test_completed(
		result_code: int,
		response_code: int,
		_headers: PackedStringArray,
		body: PackedByteArray
) -> void:
	deepl_test_button.disabled = false

	if result_code != HTTPRequest.RESULT_SUCCESS:
		deepl_test_result.text = "网络错误（%d）" % result_code
		return

	match response_code:
		200:
			var data = JSON.parse_string(body.get_string_from_utf8())
			var text := ""
			if typeof(data) == TYPE_DICTIONARY:
				var translations = data.get("translations", [])
				if typeof(translations) == TYPE_ARRAY and not translations.is_empty():
					text = str(translations[0].get("text", ""))
			deepl_test_result.text = "成功：hello → " + text
		401:
			deepl_test_result.text = "Key 无效（401）"
		403:
			deepl_test_result.text = "Key 与接口不匹配（403）"
		456:
			deepl_test_result.text = "本月额度已用完（456）"
		_:
			deepl_test_result.text = "HTTP 错误：%d" % response_code


# ---------------- 测试 AI ----------------

func _on_ai_test_pressed() -> void:
	if ai_http == null:
		ai_test_result.text = "缺少 AITestHttp 节点"
		return

	var url := ai_url.text.strip_edges()
	var model := ai_model.text.strip_edges()
	var key := ai_key.text.strip_edges()

	if url.is_empty() or model.is_empty():
		ai_test_result.text = "请先填写 Base URL 和 Model"
		return
	if ai_http.get_http_client_status() != HTTPClient.STATUS_DISCONNECTED:
		return

	ai_test_button.disabled = true
	ai_test_result.text = "测试中…"

	var body := JSON.stringify({
		"model": model,
		"messages": [{"role": "user", "content": "ping"}],
		"stream": false,
	})
	var headers := ["Content-Type: application/json"]
	if not key.is_empty():
		headers.append("Authorization: Bearer " + key)

	var err := ai_http.request(url, headers, HTTPClient.METHOD_POST, body)
	if err != OK:
		ai_test_button.disabled = false
		ai_test_result.text = "请求失败：" + error_string(err)


func _on_ai_test_completed(
		result_code: int,
		response_code: int,
		_headers: PackedStringArray,
		body: PackedByteArray
) -> void:
	ai_test_button.disabled = false

	if result_code != HTTPRequest.RESULT_SUCCESS:
		ai_test_result.text = "网络错误（%d）" % result_code
		return

	if response_code != 200:
		ai_test_result.text = "HTTP 错误：%d\n%s" % [
			response_code, body.get_string_from_utf8()
		]
		return

	var data = JSON.parse_string(body.get_string_from_utf8())
	var reply := ""
	if typeof(data) == TYPE_DICTIONARY:
		var choices = data.get("choices", [])
		if typeof(choices) == TYPE_ARRAY and not choices.is_empty():
			reply = str(choices[0].get("message", {}).get("content", ""))

	ai_test_result.text = "成功：" + reply.left(60)
```

## 3. 脚本逐块讲解

### 3.1 `_ready()`

做四件事：

1. 把所有按钮的 `pressed` 信号连到处理函数；
2. 把两个 `HTTPRequest` 的 `request_completed` 连到测试回调；
3. 设置 `SpinBox` 的范围；
4. 调用 `_load_from_settings()` 把配置读进控件。

### 3.2 `activate()`

主窗口在**切到设置页**和**窗口重新获得焦点**时都会调用 `activate()`。

这里只做一件事：

```gdscript
scroll.scroll_vertical = 0
```

**不要**在这里 `_load_from_settings()`。否则：

- 你改了设置但还没点保存；
- 切到别的窗口再切回来；
- `focus_entered` 触发 `activate()`；
- 未保存的修改被重新加载覆盖。

### 3.3 `_load_from_settings()`

把 `Settings` 里的值写进控件。

注意：

- 翻译和 AI 的 **Key 读的是 `get_value(..., "deepl_key", "")`**，不是 `Settings.deepl_key()`；
- 因为 `deepl_key()` 会优先返回环境变量，如果你把环境变量读进输入框再保存，就把 Key 写进配置文件了；
- 编辑框只负责编辑「配置文件里的值」。

### 3.4 `_save_to_settings()`

把控件里的值写回 `Settings`，然后 `Settings.save()`。

- `strip_edges()` 去掉首尾空格；
- 语言代码统一转大写（`EN` / `ZH` / `JA`）；
- `SpinBox.value` 是 `float`，用 `int()` 转成整数。

### 3.5 文件选择

```gdscript
dlg.file_mode = FileDialog.FILE_MODE_SAVE_FILE
dlg.access = FileDialog.ACCESS_FILESYSTEM
dlg.use_native_dialog = true
```

- `FILE_MODE_SAVE_FILE`：选择「保存到哪个文件」；
- `ACCESS_FILESYSTEM`：可以访问 `user://` 以外的真实路径；
- `use_native_dialog = true`：用系统文件对话框，体验更好；
- `current_path` 用 `ProjectSettings.globalize_path()` 把 `user://` 转成真实路径。

### 3.6 打开所在文件夹

```gdscript
var absolute := ProjectSettings.globalize_path(path)
var dir := absolute.get_base_dir()
if DirAccess.dir_exists_absolute(dir):
	OS.shell_open(dir)
```

- `globalize_path` 把 `user://note.md` 变成 `/home/.../.local/share/godot/app_userdata/Floatool/note.md`；
- `get_base_dir()` 取文件夹；
- `OS.shell_open(dir)` 在文件管理器里打开。

### 3.7 Key 显示/隐藏

```gdscript
deepl_key.secret = not deepl_key.secret
```

- `LineEdit.secret = true` 时显示为圆点；
- 切换按钮文字 `👁` / `🙈`。

### 3.8 测试 DeepL

- 发一个最短请求：`text=hello&target_lang=ZH`；
- 200：解析 `translations[0].text`；
- 401：Key 错；
- 403：Free/Pro 地址不匹配；
- 456：额度用完。

### 3.9 测试 AI

- 发 `messages: [{"role":"user","content":"ping"}]`；
- 200：解析 `choices[0].message.content`；
- 非 200：把响应体显示出来，方便排查；
- Key 为空时**不加** `Authorization` 头，这样 Ollama 也能用。

## 4. 接入现有三个面板

设置页只是「写配置」，真正要让配置生效，还需要三个面板**从 `Settings` 读**。

### 4.1 `panels/note_panel.gd`

把：

```gdscript
const SAVE_PATH = "user://note.md"
```

改成在读写时现取：

```gdscript
func _note_path() -> String:
	return Settings.note_path()
```

`_load()`：

```gdscript
func _load() -> void:
	var path := _note_path()
	if FileAccess.file_exists(path):
		editor.text = FileAccess.get_file_as_string(path)
```

`_save()`：

```gdscript
func _save() -> void:
	var path := _note_path()
	var f := FileAccess.open(path, FileAccess.WRITE)
	if f:
		f.store_string(editor.text)
		f.close()
		...
```

> 注意：不要在 `_ready()` 里把路径存成变量，否则设置改完要重启才生效。

### 4.2 `panels/translate_panel.gd`

把：

```gdscript
const DEEPL_URL = ...
const DEEPL_KEY = ...
```

改成每次请求时取：

```gdscript
var url := Settings.deepl_url()
var key := Settings.deepl_key()

var headers := [
	"Authorization: DeepL-Auth-Key " + key,
	"Content-Type: application/x-www-form-urlencoded",
]
var err := http.request(url, headers, HTTPClient.METHOD_POST, body)
```

如果翻译页的语言下拉想跟随设置里的默认值：

```gdscript
var default_source := str(Settings.get_value("translate", "source_lang", "EN"))
var default_target := str(Settings.get_value("translate", "target_lang", "ZH"))
```

### 4.3 `panels/ai_chat_panel.gd`

把：

```gdscript
const API_URL = ...
const MODEL = ...
func _api_key(): return "sk-..."
```

改成：

```gdscript
var url := Settings.ai_base_url()
var model := Settings.ai_model()
var key := Settings.ai_key()

var body := JSON.stringify({
	"model": model,
	"messages": _history,
	"stream": false,
})
var headers := ["Content-Type: application/json"]
if not key.is_empty():
	headers.append("Authorization: Bearer " + key)
```

系统提示词和上下文条数也改成从设置读：

```gdscript
var _history: Array = [
	{
		"role": "system",
		"content": str(Settings.get_value("ai", "system_prompt", "你是一个简洁的中文助手")),
	}
]
```

```gdscript
func _trim_history() -> void:
	var limit := int(Settings.get_value("ai", "max_history", 20))
	while _history.size() > limit + 1:
		_history.remove_at(1)
```

> 关键点：**请求时现取配置**，不要 `_ready()` 缓存。
> 这样在设置页改完、点保存后，下一次翻译/对话立即生效，不用重启。

## 5. 快捷键这块怎么理解

要区分两种：

### 5.1 全局快捷键（GNOME / KDE / Windows）

Godot **不能注册全局快捷键**。所以设置页能做的是：

- 把每个功能对应的命令显示出来；
- 提供「复制命令」按钮；
- 让用户去桌面环境里绑定。

你的 `HotKeySection/Label` 里现在是：

```text
/bin/bash -c 'printf %s note > /dev/udp/127.0.0.1/45670'
/bin/bash -c 'printf %s translate > /dev/udp/127.0.0.1/45670'
/bin/bash -c 'printf %s aichat > /dev/udp/127.0.0.1/45670'
```

建议补充：

```text
/bin/bash -c 'printf %s settings > /dev/udp/127.0.0.1/45670'
```

`CopyButton` 按下时：

```gdscript
DisplayServer.clipboard_set(hotkey_label.text)
```

### 5.2 应用内快捷键（Ctrl+S / Ctrl+Enter / Ctrl+1…）

这些是程序内部的，理论上可以做成「可配置」：

1. Project Settings → Input Map 建 action；
2. 设置页录制按键；
3. 把 keycode/modifiers 存到 `settings.cfg`；
4. 启动时应用到 `InputMap`。

但第一版建议**只读展示**，不要开放修改：

- 全局快捷键才是你日常用的；
- 应用内快捷键改起来涉及 InputMap 序列化，工作量大；
- 等核心功能稳定后再做。

## 6. 测试清单

1. 打开设置页，字段是否正确显示当前配置；
2. 修改便签路径，点「保存设置」，去便签页保存一次，确认写到新路径；
3. 点「浏览…」，选一个 `.md` 文件，路径是否正确回填；
4. 点「打开所在文件夹」，文件管理器是否打开对应目录；
5. 翻译 Key 点「👁」能否切换明文/密文；
6. 点翻译「测试连接」：
   - 正确 Key → 成功；
   - 错误 Key → 401；
   - Free Key 用 Pro 地址 → 403；
7. 点 AI「测试连接」：
   - 正确 Key/URL/Model → 成功；
   - 空 Key + Ollama → 成功（不加 Authorization）；
8. 保存后，去翻译页/AI 页直接使用，**不重启**是否生效；
9. 重启程序，设置是否还在（`user://settings.cfg`）。

## 7. 常见坑

| 现象 | 原因 | 解决 |
|------|------|------|
| `Script inherits from native type ...` | `extends` 和根节点类型不一致 | 根是 `MarginContainer` → `extends MarginContainer` |
| `Settings` 未定义 | 没注册 Autoload | Project Settings → Globals 添加 `Settings` |
| 设置改了不生效 | 面板在 `_ready()` 缓存了配置 | 改成请求时现取 |
| 保存后 Key 变了 | 读的是 `deepl_key()`（环境变量优先） | 编辑框读 `get_value(..., "deepl_key", "")` |
| 测试按钮没反应 | 没加 `DeepLTestHttp` / `AITestHttp` | 按 1.1 添加节点 |
| 文件对话框打不开 | `access` 没设 `ACCESS_FILESYSTEM` | 改成 filesystem |
| 打开文件夹没反应 | 路径是 `user://` 开头 | 先 `ProjectSettings.globalize_path()` |
| AI 测试 401 | Key 错 / 没加 Authorization | 检查 Key 和 headers |
| AI 测试 404 | URL 少了 `/chat/completions` | 检查 Base URL |
| `SpinBox.value` 类型 | 它是 float | 保存时 `int(ai_history.value)` |
| 切窗口后未保存内容丢了 | `activate()` 里重新 load | 不要重新 load，只滚回顶部 |

## 8. 安全提醒

1. **不要再把 Key 硬编码在脚本里。**
   你现在的 `translate_panel.gd` / `ai_chat_panel.gd` 里已经有真实 Key，建议立刻去对应后台**吊销并重新生成**。

2. `user://settings.cfg` 里存的是**明文** Key：
   - 个人使用可以接受；
   - 要发布给别人，建议走自己的后端代理，或让用户自己填；
   - 不要把这个文件提交到 git（它在 `user://` 下，本来就不在仓库里）。

3. `Settings.deepl_key()` / `Settings.ai_key()` 已经优先读环境变量：
   - `DEEPL_API_KEY`
   - `DEEPSEEK_API_KEY`

   适合开发时避免把 Key 写进配置文件。

4. 设置页的「测试连接」会把请求发到对应 API，注意不要在公共电脑上留下 Key。

---

## 9. 一句话总结

- **设置页只负责「编辑 + 保存」**，配置读写统一走 `Settings`；
- **业务面板在请求时现取配置**，不要 `_ready()` 缓存；
- **全局快捷键只能展示命令**，真正绑定交给桌面环境；
- **测试连接**用两个独立 `HTTPRequest`，避免和业务请求抢同一个节点；
- **Key 不要硬编码，也不要提交到仓库**。

按这个结构，你的设置页就能把便签路径、翻译 API、AI API、快捷键说明统一管理起来。
